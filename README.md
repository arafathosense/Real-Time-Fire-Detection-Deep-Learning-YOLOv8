**Real-Time Fire Detection with Deep Learning (YOLOv8)**

**🧠 Installation & Setup**

**Step 1**

Download the source code and open the project folder in PyCharm.

**Step 2**

Go to: File → Settings → Python → Interpreter Then click the “+” icon and install the following packages:

    pip install ultralytics
    pip install opencv-python
    pip install cvzone


**Step 3**

Now just run the program — and you’re done! ✅

**Step 4**

If you want to do **real-time detection**, then start any fire video from **YouTube** on your phone and point it at the **laptop**. You can see the result directly. For that, go to line 11.

**Change this line 11** 
      
      cap = cv2.VideoCapture(0)
      
Now run and see the result.
